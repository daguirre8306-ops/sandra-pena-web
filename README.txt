WEB SANDRA PEÑA

Proyecto estático, listo para publicar en cualquier hosting estático.

ANTES DE PUBLICAR
1. En script.js completar SITE_CONFIG.whatsapp (solo números, incluido 54 y código de área).
2. Completar SITE_CONFIG.siteUrl con el dominio definitivo. Esto activa el canonical y completa los datos estructurados.
3. Reemplazar TU-DOMINIO en robots.txt y sitemap.xml.
4. Si existe Instagram real, completar SITE_CONFIG.instagram.

ANALÍTICA
Cuando estén disponibles, pegar Google Analytics 4, Meta Pixel y la verificación de Search Console dentro de head en index.html. No se dejaron identificadores ficticios.
